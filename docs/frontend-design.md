# 网站诊断工作台设计

全部开发、构建和测试文件位于当前项目。用户已明确选择跳过 AI 概念图，采用代码实现。该界面在本机使用，直接调用原项目的 Python 诊断、故障实验和评测能力。

## 视觉规范

- 品牌：NetLens，中文名称“网站诊断工作台”。整洁、安静、偏工程产品的浅色界面。
- 颜色：页面 #f5f7f8，侧栏及面板白色，主文字 #182c28，次文字 #74817d，主色 #174d3d，浅绿 #edf5ef，边框 #e5eae7。成功为绿色、异常为赭红、运行中为蓝色，状态同时配有文字和图标。
- 字体：系统中文字体和 Segoe UI；主标题 30px，区域标题 18px，正文 14px，辅助文字 12px。数字采用等宽或 tabular-nums。
- 形状：主面板圆角 16px，输入和按钮 9px，侧栏选中项 8px。仅关键检测区使用轻阴影，不堆叠装饰卡片。
- 排版：桌面 224px 左栏，内容区最大 1240px，主要区域左右双列（主操作区与调查提示）；窄屏切为单列，侧栏变成可展开的导航。
- 图标：一致的 1.7px 线条 Lucide 图标。运行中使用轻微脉动；尊重 prefers-reduced-motion。

## 页面和交互

1. 网站诊断：网址输入、模型选择、Skill/工具/直接分析模式、可展开的超时与慢响应设置、真实任务进度。空状态说明检测范围；结束后显示结果、原始测量、分阶段证据、建议、校验记录和报告下载。
2. 故障实验室：七个案例，标明真实本机探测与模拟数据。支持真实模型与规则工具测试，规则结果清楚标记；本地服务生命周期沿用原工程。
3. 对照评测：选择案例、A/B/C 模式、模型和重复次数；展示逐项进度与汇总表，区分首次草稿、最终成绩和程序辅助修正。已有历史结果可查看，不编造实验数据。
4. 报告档案：读取 results 中现有真实报告；搜索和结果类型过滤；查看完整报告、JSON、原始证据和模型校验记录；JSON/Markdown 下载。
5. 运行设置：检查 Ollama 连接、选择模型、设置本机 Ollama 地址和默认检测参数；非敏感偏好保存在带版本号的 localStorage 中。显示无需模型的工具测试入口和实际输出位置。

## 状态与边界

- 首次进入不自动检测外部网站，不预填虚假成功结果。
- 进度来自后端工具和模型事件，不使用随机或定时伪造的完成百分比。
- 运行中、排队、失败、停止和完成均有明确状态；停止操作等待当前网络调用结束后生效。
- 模型执行失败仍展示已取得的工具事实，程序结论和模型结论分区显示。
- 历史报告保留原样，观测回放和模拟来源保持标记。文字修正的程序辅助说明可展开查看。
- 服务仅绑定 127.0.0.1；文件读取限制在项目结果目录，POST 校验来源，不允许网页执行命令或改变系统网络配置。

## 验证流程

页面加载 → 配置运行参数 → 执行本地故障案例 → 查看实时阶段和真实结果 → 下载报告 → 在档案中重新打开；同时验证参数错误、缺少模型、停止任务和窄屏排版。

## 实现与验收记录

- 使用 React + Vite 实现五个功能页面，Python 标准库提供同源 API 和静态资源。已交付构建目录，日常运行只需 Python；包含 run.py 的内层目录提供 `start-web.cmd`。
- 按用户选择跳过 AI 概念图，使用上述文字视觉规范。视觉验收直接检查内置浏览器中的实际页面。
- 桌面 1440×960、手机 390×844 均已检查。手机主表单、模型选择器不越出面板，页面无横向溢出；导航可展开，关闭时不参与键盘焦点。
- 视觉检查点：主导航和五页信息层次、网址表单及按钮对齐、系统中文字体与次级文字可读性、白色面板和墨绿色重点色、检测阶段与结果状态配色、手机表单布局、报告表格的受控横向滚动。修正了初版小字号和弱对比度、手机下拉框裁切、侧栏未收起时的焦点问题。
- 浏览器真实操作验证：空网址错误提示；本机 HTTP 503 案例运行；查看三项原始证据；档案搜索空结果和重新打开报告；两案例规则评测；运行设置保存；帮助弹窗；本机工作台 HTTP 200 诊断；运行中停止后续步骤；Ollama 未启动时显示真实失败。
- 下载通过 HTTP 层验证 Markdown 内容和下载头，没有触发浏览器默认下载目录。临时测试文件使用项目内 `work/tests/` 并自动清理。
- 初次构建中的 JSX 运行方式不匹配已修正；最后浏览器检查没有新的控制台错误，也没有框架错误遮罩。最新构建通过，42 个 Python 测试全部通过。
- 当前本机 Ollama 服务未启动，因此本轮网页验收验证了规则链路和模型连接失败状态，没有把它当作新的真实 LLM A/B/C 成绩。启用模型仍需启动本地 Ollama 并选择已下载的模型。
